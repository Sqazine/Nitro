### 2. 功率放大（PowerAmp.h）修复"动态塌陷"缺失 bug
- **原 bug**：sag 包络 `mEnv += (inst-mEnv)*0.005f` 是固定每采样系数 → 4x 过采样时时间常数缩到 ~1ms，且归一化 `*0.05` 太小使 sag 恒等于常数 −3.4dB（无动态压缩/绽放）。
- **修法**：`setSampleRate` 里用 `dt` 推导 attack(~2ms)/release(~60ms) 系数（`1-exp(-1/(τ*sr))`），与采样率无关；`sagF = 1 - sag*clamp01(env*mEnvNorm)`，`mEnvNorm=0.005` 让压缩在轻柔~0.98 到 cranked~0.70 之间渐进。新增 `dbg_sag` 探针。
- 功率管拐点 `drive` 0.01→0.015（真实栅驱动尺度），master 0.8→0.5（整体电平不变）。

### 3. 前级"清音余量"修复（去"全程一样 crunch 的塑料感"）
- **问题**：`stage2Drive = mInterstageScale*(0.4+1.6*gain)` 有 0.4 下限且 `mInterstageScale=0.5` → 即使 gain=0.2，V2a 也被驱入栅流、LTP 被砸到 ±134V，所有档位一样狠 → 无清音→crunch 动态。
- **修法**：`stage2Drive = mInterstageScale*(0.05 + 1.95*gain)`，`mInterstageScale` 0.5→0.40。
- **自检验证**（RESULT: OK，峰 0.23–0.49 安全）：
  - clean 440：`maxVgk2=-0.72V`（V2a 栅不导通→真清音），THD 0.62%
  - default 440：`maxVgk2=+0.10V`（轻 grind），THD 0.76%
  - cranked 440：`maxVgk2=+0.40V`，THD 1.03%
  - cranked 1k：`maxVgk2=+0.79V`（强栅流 grind），THD 2.70%
- 重新编译 VST3 通过，拷 `JCM800/JCM800.vst3`。

## 合成箱体改为 Greenback 4x12 闭背最小相位 IR（用户指令"Cabinet 还要支持模拟合成 GreenBack 4x12 closed 音箱声音"）

保留已实现的测量 IR 接入能力不变，把**合成 IR** 从"偏平坦的离散阻尼模态求和"改写成**真正有 Greenback 音色的目标频响最小相位合成**。

### 做法
- `Cabinet.h::gbTarget(f)` 定义目标幅度谱：70Hz 以下 sub-cut、95Hz thump 隆起、1.8kHz cone-cry 隆起、4.5kHz 以上平滑滚降（floor 0.04 防止倒谱条件数差）。
- `Cabinet.h::fft()` 自实现 radix-2（正反变换）。`generateIR()`：目标幅度谱→对称填充→FFT 取 log→复倒谱→因果化（留 0..N/2）→FFT→exp→IFFT 得**最小相位 IR**（N=mLen=8192=2^13，非 2 的幂走单位脉冲回退）。最小相位 = 平滑、无模态间零点、自然衰减。
- `kDefaultLen` 4096→**8192**（~186ms@44.1k，容纳更长尾音）。`mSr` 提到 public（自检读频响用）。

### normalizeIR() 顺带修了一个真 bug
- 旧实现用卷积峰值 `if (n > L && ...)` 求各参考频带稳态增益，但 `RN=8192 == L=8192` 时 `n>L` 永不成立 → `maxGain` 卡在 `1e-9` → `gnorm=1e9` → 箱体输出爆炸到 ~2.3e8。改成**直接用 DTFT 幅度 |H(f)|**（精确稳态增益），任何 L 都正确。修后箱体输出峰稳定在 ~0.49，宿主安全。

### 自检验证（`self_test.cpp` + `build_selftest.bat`，无 JUCE）
- 合成 FR(dB, 0dB=峰)：50Hz −6.2 / 95Hz −0.56 / 1.8k 0.0 / 中频(150–1k) ~−1.7 / 4.5k −4.6 / 6k −5.8 / 8k −7.4 → 典型 Greenback 形（thump+cone-cry+平滑高频滚降+sub-cut）。
- 链路峰/栅流：clean(gain0.05) `maxVgk2=-0.871`（真清音，V2a 不栅流）；edge(gain0.2) +0.051；cranked(gain0.95) +0.642。峰均 ~0.49。非有限=0。
- 注：测得 THD 偏高(~50–86%)主要由**功放软饱和**(tube() 压缩，与增益无关、pre-cab 峰恒 0.816)贡献；箱体是线性 FIR 不引入谐波失真，非本次改动引入。
- WAV 往返 `RESULT: OK`（maxErr=0.00000）。
- `self_test` 额外写出 `synth_greenback.wav`（合成 IR）供试听。
